# Known limitations

- Experimental APR import and derived interval/network review validated with synthetic fixtures only; no real export/version conformance or physical device. Unknown/malformed records remain warnings, not silently successful coverage.
- Periodicity input is deliberately synthetic-only in M1. APR aggregate counts cannot support interval analysis. No real network acquisition/PCAP parser, TLS payload inspection, actor attribution or universal spyware verdict.
- Only exact domain IOC equality. No STIX, process/hash IOC, authenticated feed/freshness, calibrated detection accuracy or complete history. Legitimate sync and missing observations remain alternatives.
- Original bytes preserved and checked, but read-only mode is not immutable storage; audit is not externally anchored/signed. Same-user/root attackers and fully rewritten metadata are outside the integrity claim. Private files are not encrypted.
- Store is bounded JSON, POSIX-only, advisory locks, no crash recovery UI. Hostile local path-race hardening is incomplete. Actual performance experiment and initial failed RSS budget are recorded in ADR-001.
- Internal Case/Artifact/RuleRun state uses dictionaries; Event/Finding have dataclasses. Runtime metadata validation now rejects unexpected fields, invalid provenance/clock/runtime types, missing audit roots and inconsistent import/review/run history. Events are reparsed and exported analysis is recomputed. JSON Schema conformance tests remain a separate development gate; a full typed persistence model replacement is future work. Metadata validation is not authentication against a party able to rewrite the entire case.
- Redacted reports retain timestamps/hashes; they are not anonymous. Console redirection permissions are the shell's responsibility.
- No archive extraction; corrupt/malicious ZIP/tar/plist tests prove refusal, not safe extraction. Optional AI investigation now has tested tool/OS boundaries, but synthetic injection tests do not establish real-model resistance to persuasion. Hypothesis entailment remains unverified.
- No forensic upstream source/binaries adopted. Investigation dynamically requires system libseccomp (LGPL 2.1); it is not bundled. Licensing remains open for future integrations. Upstream selected-source review is not a full security audit. Additional suggested projects beyond documented sources remain research backlog.
- Dev dependencies pinned by version, not wheel hash; CPython/native dependency vulnerabilities and full transitive license inventory are not guaranteed covered by package-advisory checks.
- Benchmarks are one shared Linux host and synthetic records; no native Rust/Go/Swift benchmark, cross-platform packaging, adversarial max-memory proof or long-running capture performance guarantee.

- Privacy review pairs intervals within each original artifact, never across exports. Exact byte duplicates are collapsed for interpretation only; divergent metadata yields ambiguity. Unknown boundary/resource/identifier fields remain unresolved. Counts and durations are not combined into cross-export totals. Source identifiers do not establish device/app-installation identity.
- `--include-identifiers` is an explicit local JSON disclosure mode; default redaction does not make timestamps, hashes or relationships anonymous. Privacy review generation is read-only and binds to the existing audit tip; report exports do not append a new audit event.

- IPS JSON supports only the explicit 309/298 subset; original generated fixtures and Apple documentation are not real-export qualification. Text resource reports, stackshots, panic logs, older schemas, symbolication and full field coverage are absent.
- Investigator: Linux/libseccomp only, fixed read-only tools, earliest 2,000 events by default and a 16 MiB snapshot. Chronological selection can omit later or unknown-time evidence. Results over 64 KiB fail explicitly; large finding sets and identifier-rich records may require a narrower case.
- Local/remote HTTP adapter contract and TLS certificate checks use synthetic peers. No actual local model or external provider has been tested. Loopback alone does not guarantee the model server is offline. Native provider-specific APIs, streaming and automatic retries are unsupported.
- Remote disclosure digest is an explicit CLI scope acknowledgment, not identity authentication or a signed consent record. Provider retention, pricing and model quality are unverified. Token reservations are estimates, not hard provider billing limits.
- Reports carry untrusted model plans/questions/hypotheses. Exact field claims and deterministic measurements are validated; source truth and hypothesis semantics are not. No automatic saving/resume, unrestricted plugins, MCP server or autonomous acquisition exists.
